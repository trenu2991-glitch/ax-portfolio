[결정 사항]
- 헤드라인: "환자 한 사람의 식탁을, 근거로 설계합니다"
- 부제: 병원 임상영양 실습 4주 · 케이스 스터디 2건
- 섹션 순서:
  첫 화면 → 케이스 스터디 → 환자용 설명 자료
  → 상담 연습 → 이 사이트를 만든 과정 → 연락처
- 케이스 카드 구성: 문제 / 내가 확인한 것 /
  판단과 조정 / 결과 / 지도 피드백
- 케이스 카드마다 "비식별 가상 사례" 배지

[만들 것]

- 차분한 녹색 계열, 휴대폰 폭 375px에서도 깨지지 않게
