[결정 사항]
- 헤드라인: "현장의 반복 확인을, 실수를 줄이는 도구로 바꿉니다"
- 섹션 순서: 첫 화면 → 문제(2시간의 반복) → 도구 체험
  → 수작업과의 대조 결과 → 영양사로서 내가 정한 규칙
  → 이 사이트를 만든 과정 → 연락처

[도구]
- 입력: 한 줄에 "메뉴명: 재료, 재료, …"
- 버튼을 누르면 메뉴별로 해당 표시 대상 항목을 표로 표시
- 아래 [표시 대상과 동의어]로만 판단
- 표 아래 고정 문구: "가공품은 제품 표시를 확인하세요.
  이 도구는 보조 수단입니다."
- 예시 입력 3줄을 미리 채워 둬
  (잡채: 당면, 돼지고기, 간장, 시금치 등)
