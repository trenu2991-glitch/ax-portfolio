[상황] 나는 식품영양학과 4학년 정민재(특강용 가상 인물)야.
식생활·건강 아이디어 공모전 심사위원과 식품기업 혁신 부서
담당자에게 보여줄 포트폴리오 웹사이트를 만들려고 해.
사이트 안에서 내가 만든 작은 도구가 직접 작동해야 해.
아직 코드는 쓰지 마.

[기획 메모]
- 30초 문장: 현장의 반복 확인을 실수를 줄이는 도구로 바꾸는 사람
- 증거: 작동하는 알레르기 확인 도구, 수작업 결과와의 대조표,
  기준 목록을 고시 원문과 대조한 기록
- 지킬 것: 도구는 보조이고 최종 확인은 영양사라고 밝힌다
- 하지 않을 것: "완벽", "100%" 같은 단정

[요청]
1. 보는 사람이 첫 30초 안에 알아야 할 것 3가지
2. 첫 화면 헤드라인 후보 3개와 각각의 인상
3. 섹션 구성안 2가지 — 도구를 어디에 둘지 포함
4. 사실 확인이 꼭 필요한 부분 목록

[규칙] 재료에 없는 경력·수치·수상은 만들지 마.

[재료]
- 영양사 국가시험 준비 중
- 급식소 실습 4주 (가상): 주간 식단표의 알레르기 유발
  식재료를 레시피를 한 줄씩 보며 사람이 표시 → 1주 식단
  확인에 약 2시간
- 해결: AI 에이전트로 웹 도구 제작 — 메뉴별 재료를 넣으면
  표시 대상 항목과 대조해 해당 항목을 표시
- 시험: 실습 식단 4주분(메뉴 80개)으로 수작업 결과와 대조
  1차 불일치 6건 → 원인: 재료 표기가 달라 못 찾음
  (계란/달걀, 마요네즈 속 달걀 등) → 동의어 추가
  2차 불일치 1건 → 원인: 가공품 원재료 미기재
  → "가공품은 제품 표시를 사람이 확인" 규칙 추가
- 결과: 1주 식단 확인 약 2시간 → 약 30분
