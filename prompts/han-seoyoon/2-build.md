[결정 사항]
- 헤드라인: "남는 음식을 숫자로 읽고, 줄이는 방법을
  설계합니다"
- 첫 화면: 헤드라인 + 큰 숫자 "31% → 22%"
  + 한 줄 설명 "조정한 5개 메뉴의 평균 잔반률"
- 섹션 순서:
  첫 화면 → 잔반 줄이기 프로젝트(문제·분석·제안·결과)
  → 원가 비교 작업 → 이 사이트를 만든 과정 → 연락처
- 결과 부분: 메뉴별 조정 전·후 잔반률 막대그래프
- 연락처: seoyoon.han@example.com

- 이 폴더에 index.html 파일 하나, CSS·JS는 파일 안에
- 외부 라이브러리 없이 막대그래프를 직접 그려 줘
- 막대그래프는 원자료 표로 메뉴별 조정 전·후 잔반률을 계산해 그려
- 휴대폰 폭 375px에서도 깨지지 않게, 파란색 계열
